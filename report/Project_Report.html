Pet Adoption Center Manager

1. Introduction

The Pet Adoption Center Manager is a Java Swing desktop application developed to simplify pet registration, adopter management, adoption requests and adoption record maintenance.

2. Objectives

  • Maintain accurate pet and adopter information.
  • Simplify the adoption request and approval process.
  • Prevent duplicate adoption records and duplicate pending requests.
  • Provide persistent data storage using CSV files.
  • Demonstrate Java OOP concepts in a practical project.

4. Implementation

The project uses separate model, manager and file-management classes:

  • Pet, Adopter, AdoptionRequest, AdoptionRecord: domain models.
  • PetManager, AdopterManager, AdoptionManager: CRUD and adoption workflows.
  • FileManager: safe CSV loading, saving and exporting.
  • Dashboard: application layout and Swing interface.
  • Main: application entry point.

5. Java OOP Concepts

  • Classes and objects
  • Constructors and methods
  • Encapsulation through private attributes and public accessors
  • Collections such as ArrayList and streams
  • Exception handling and input validation
  • File handling
The approval workflow verifies availability, changes request status and pet status, and creates exactly one adoption record.
